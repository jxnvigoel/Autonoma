## 2. Journeys

### J-1: Specimen Check-In & Barcode Generation ([P-01]) — covers [F-001 / FR-01], [AC-001], [AC-002]
1. On `S-01` (Dashboard) → Lab Technician (`[P-01]`) clicks the "New Specimen Intake" tile to initiate the intake workflow.
2. `S-02` (Specimen Check-In Console) loads → Lab Technician (`[P-01]`) inputs the unique accession identifier, sample type, and biological source details into the metadata form (`[API-001]`).
3. **Success**: System validates the metadata, generates a 2D barcode payload, writes the record to local SQLite (`[TBL-01]`), displays a printable barcode preview, and updates the view within 5 seconds (`[AC-001]`, `[NFR-01]`).
4. **Error (invalid input)**: If the accession identifier is a duplicate or the sample reference is missing, inline validation notices highlight the specific offending fields with red borders and descriptive text, retaining all entered input without data loss (`[AC-002]`).
5. **Error (system / storage error)**: If the local database write times out, a non-blocking warning banner appears at the top of the console notifying the user of the storage failure with an actionable 'Retry' button to re-attempt persistence (`[AC-002]`).

### J-2: Cold-Storage Excursion Logging ([P-02]) — covers [F-002 / FR-02], [AC-003], [AC-004]
1. On `S-01` (Dashboard) → Cold Chain Monitor (`[P-02]`) clicks the "Active Alerts" widget to review flagged storage units.
2. `S-03` (Temperature Excursion Log) loads → Cold Chain Monitor (`[P-02]`) selects the flagged storage unit, reviews the peak temperature reading, and enters mandatory incident notes regarding the deviation (`[API-002]`).
3. **Success**: System flags the excursion alert, logs the peak temperature and incident notes to the local database (`[TBL-02]`), and confirms the incident record creation within 5 seconds (`[AC-003]`, `[NFR-01]`).
4. **Error (invalid input)**: If the sensor input is unreadable or the unit identifier is invalid, the system records a diagnostic warning, marks the reading as "unverified" in the log, and prevents any false excursion clears from being processed (`[AC-004]`).
5. **Error (system / storage error)**: If the logging service fails to persist the incident note, a non-blocking warning banner notifies the user of the write failure with an actionable 'Retry' button to ensure the audit trail is not compromised (`[AC-004]`).

### J-3: Custodial transfer sign-off with digital confirmation ([P-01]) — covers [F-003 / FR-03], [AC-005], [AC-006]
1. On `S-01` (Dashboard) → Lab Technician (`[P-01]`) selects 'Custodial Transfer Sign-Off' from the operational navigation panel.
2. `S-04` loads → Lab Technician inspects existing entries and submits required parameters for custodial transfer sign-off with digital confirmation via `[API-003]`.
3. **Success**: System authenticates custodial transfer sign-off with digital confirmation signatures, commits record to local SQLite table `[TBL-03]`, renders confirmation notification, and persists state within 1.0 s ([AC-005], [AC-006], `[NFR-01]`).
4. **Error (invalid input)**: Security boundary prompt highlights missing credentials for custodial transfer sign-off with digital confirmation, keeping staged custody parameters for immediate correction ([AC-005], [AC-006]).
5. **Error (system / storage error)**: Non-blocking banner notifies user of temporary SQLite database lock during custodial transfer sign-off with digital confirmation, offering an actionable 'Retry Action' button ([AC-005], [AC-006]).

### J-4: Regulatory inspection audit export ([P-03]) — covers [F-004 / FR-04], [AC-007], [AC-008]
1. On `S-01` (Dashboard) → Quality Auditor (`[P-03]`) selects 'Regulatory Audit Export' from the operational navigation panel.
2. `S-05` loads → Quality Auditor inspects existing entries and submits required parameters for regulatory inspection audit export via `[API-004]`.
3. **Success**: System compiles regulatory inspection audit export manifest, archives output to local SQLite table `[TBL-04]`, prompts file save confirmation, and finalizes export within 1.0 s ([AC-007], [AC-008], `[NFR-01]`).
4. **Error (invalid input)**: Configuration notice flags invalid date range or schema for regulatory inspection audit export, keeping selected parameters intact ([AC-007], [AC-008]).
5. **Error (system / storage error)**: Storage failure notification displays local file write error during regulatory inspection audit export, featuring a direct 'Retry' button ([AC-007], [AC-008]).
